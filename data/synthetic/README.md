# Synthetic data

Everything here is invented for LimauPay, a **fictional** Malaysian e-wallet. Limits, script IDs
and procedures are made up for the project and do not describe any real company or regulation.
Never add real customer data.

You can also upload public documents (for example Bank Negara Malaysia policy documents
downloaded from bnm.gov.my) with `source_type=regulation` to test retrieval on real-world text.
